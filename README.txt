IPPGOnline Print Master v1

Canonical page:
8.5 x 11 inches
300 DPI coordinate system
2550 x 3300 pixels

Open index.html in Chrome or Edge.

The browser preview scales the 2550 x 3300 master to fit the screen without changing its geometry.
Use the Save / Print PDF button, then choose Save as PDF in the browser print dialog.

- Paper: Letter
- Orientation: Portrait
- Margins: None
- Scale: 100%
- Background graphics: On
